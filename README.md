# ARTICULA

Article browsing and management app. Final project of a front-end course.

## What it does
- Browse the articles of all users, with their details, loaded from the API.
- Search and filter the article list through the API.
- Create, edit and delete articles.
- Create, edit and delete User accounts and show user dashboard.

## Built with
React, JavaScript (ES6+), CSS Modules, REST API (Fetch API and promises)
Forms are controlled components managed with React state, without a form library.

## About this project
The main pages follow a Figma design provided by the course. The API endpoints were tested with a provided Postman collection before being connected to the app.

## Run locally
* npm install
* npm run dev
