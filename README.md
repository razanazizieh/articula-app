# ARTICULA

Article management dashboard. Final project of a front-end course.

## What it does
- Create, edit and delete articles.
- Connects to a REST API using the Fetch API

## Built with
React, JavaScript (ES6+), CSS Modules, REST API

## About this project
The main pages follow a Figma design provided by the course. The API endpoints were tested with a provided Postman collection before being connected to the app.

## Run locally
npm install
npm run dev
